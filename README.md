# AvaloniaConstructGenerator

[![NuGet](https://img.shields.io/nuget/v/AvaloniaConstructGenerator.svg?style=flat-square)](https://www.nuget.org/packages/AvaloniaConstructGenerator/)
[![NuGet Downloads](https://img.shields.io/nuget/dt/AvaloniaConstructGenerator.svg?style=flat-square)](https://www.nuget.org/packages/AvaloniaConstructGenerator/)

A Roslyn Source Generator that automatically creates parameterless constructors for Avalonia UI Windows and Pages (`Avalonia.Controls.Window`, `Avalonia.Controls.Page`).

## Why is this needed?
The Avalonia XAML designer requires a parameterless constructor to instantiate and preview your controls. If you use Dependency Injection (DI) and your Window or Page only has a constructor with parameters (e.g., injected services or ViewModels), the designer will fail to load the preview.

This source generator automatically detects classes inheriting from `Window` or `Page` and generates the required parameterless constructor in a separate generated file. The generated constructor is marked with `[Obsolete("For Avalonia Designer only", true)]` to prevent accidental usage in your actual code.

## Installation

Install the package via NuGet:

```bash
dotnet add package AvaloniaConstructGenerator
```

To ensure the generator doesn't become a runtime dependency of your project, it is recommended to add `PrivateAssets="all"` in your `.csproj`:

```xml
<PackageReference Include="AvaloniaConstructGenerator" Version="1.0.1" PrivateAssets="all" />
```

## Usage

The only requirement is that your Window or Page class must be marked as `partial`.

**Your code (`MainWindow.axaml.cs`):**

```csharp
using Avalonia.Controls;
using MyProject.Services;

namespace MyProject.Views;

// 1. The class must be partial
public partial class MainWindow : Window
{
    // 2. You can have your parameterized constructor for DI
    public MainWindow(IMyCustomService service)
    {
        InitializeComponent();
        // ...
    }
}
```

**Generated code (invisible, strictly for the designer):**

```csharp
// <auto-generated/>
using System;

namespace MyProject.Views
{
    partial class MainWindow
    {
#pragma warning disable CS8618
        [Obsolete("For Avalonia Designer only", true)]
        public MainWindow()
        {
            InitializeComponent();
        }
#pragma warning restore CS8618
    }
}
```

## Supported Types
The generator currently detects and generates constructors for classes inheriting from:
* `Avalonia.Controls.Window`
* `Avalonia.Controls.UserControl`
* `Avalonia.Controls.Page` (including derived types like `ControlPage`, `DrawerPage`, etc.)
